# Phase 2.7 验证记录

日期：2026-09-09。状态：**PASS**。

本阶段只优化 Windows 桌面课程表时间轴与课程卡片的对应关系。用户提供的手机截图只作为节次/时间组织逻辑参考；没有采用手机导航、窄列、高密度排版或移动端交互。

## 实现边界

- 左侧 TimeAxis 继续使用连续分钟定位。每个节次块分别展示“第 N 节”、开始时间和结束时间；高度严格等于节次真实分钟数。小于 42px 的节次仍以两层呈现，完整时间段置于节次下方，不增加高度。
- 课程区移除小时、半小时、节次和列分隔线，只保留时间表外框及课程卡片自身边界。课程 top 和节次继续由同一连续分钟计算得出。
- 时间表保持单一 `.timetable-scroll`，星期表头和时间轴继续 sticky。时间轴宽度为 124px，日列最小宽度为 154px；1280×800 尽量完整展示，较小窗口通过横向滚动保留列宽。
- 课程卡片继续只由 `startTime`、`endTime` 和 `pxPerMinute` 决定 top/height。普通卡片增加桌面内边距、圆角、轻边框、轻阴影与低饱和稳定配色；没有改为离散节次格。
- 卡片不再用省略号或隐藏教室/教师来处理短课。卡片根据真实高度、内容量和 overlap lane 宽度选择 regular、small、micro 或 tiny 文字层级；45 分钟测试课程仍显示课程名、时间、教室和教师。极端文本仍保留完整 `title` 与 `aria-label`，以便键盘和辅助技术读取。
- 作息设置、SQLite、CRUD、精确节次匹配规则不变。改变作息后，PeriodTime 立即重绘；Course 实际时间不被改写，时间不匹配的课程只显示实际时间。
