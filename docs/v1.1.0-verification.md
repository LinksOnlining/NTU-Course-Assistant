## Remaining gate

The existing installed application process was running during the local NSIS upgrade attempt. The installer returned exit code 0, but the running installed executable was not replaced, so installed-state smoke testing remains part of the user acceptance gate. P9-003 and P9-004 become VERIFIED only after the v1.1.0 installed application passes that check.

## User acceptance checklist

1. Confirm the new subtitle and absence of the old custom-schedule notice.
2. Edit the first and a middle period; later periods should keep their duration and breaks.
3. Save, truly exit, relaunch, and confirm the schedule remains saved without a permanent saving state.
4. Test previous/next week, return to current week, 5/7-day view, weekend notice, today highlight, current-time line and initial scroll position.
5. Import the previously affected text PDF; it must not be called a scan. An unsupported text layout must show the structure message.
6. Confirm Tray, Widget and test notification have no visible regression.
