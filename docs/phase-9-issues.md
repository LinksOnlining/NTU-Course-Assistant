# Phase 9 用户体验问题

Phase 9.1 已开始。此记录只收集用户实际体验中提出的问题；未记录问题前不主动修改功能。

## 状态

- Blocking：0
- High：1（已延期）
- Open：0
- Deferred：2

## P9-001

- 类型：UI
- 现象：用户课程卡片显示“用户添加”，长内容在 90 分钟卡片中层级拥挤。
- 期望：正式卡片不显示来源标记；名称、时间、教室和教师都保留，空间不足时缩小字体。
- 严重程度：Medium
- 状态：VERIFIED
- 修改范围：`CourseCard`、课程卡片 CSS、相关 UI 测试。
- 验证：针对性 UI 测试通过，用户完成 Phase 9 人工验收后确认。

## P9-002

- 类型：UI
- 现象：课程表主体与“大学课程表”标题区距离过大。
- 期望：课程显示区域向上靠近标题，同时保留所有状态提示。
- 严重程度：Low
- 状态：VERIFIED
- 修改范围：主页面垂直间距 CSS。
- 验证：用户完成 Phase 9 人工验收后确认。

## P9-003

- 类型：PDF
- 现象：一次导入显示“当前 PDF 可能是扫描版，首版暂不支持”。
- 期望：文字型课程表进入解析预览；扫描 PDF 继续给出准确提示。
- 严重程度：High
- 状态：DEFERRED
- 修改范围：待后续修复 PDF 导入在正式 Release 中的扫描版误判/提示问题。
- 验证：当前 Release 仍复现该问题；后续新增功能时一并修复并重新人工验收。

## P9-004

- 类型：设置 / Bug
- 现象：发布的 Release 中保存设置仍未完全生效，用户观察到设置无法可靠保存。
- 期望：作息、提醒、小组件等设置保存后立即生效，重启后仍能恢复。
- 严重程度：High
- 状态：DEFERRED
- 修改范围：待后续新增功能时一并修复设置持久化链路。
- 验证：当前 Release 仍未解决；修复后需要在 Release 安装态重新验证。
