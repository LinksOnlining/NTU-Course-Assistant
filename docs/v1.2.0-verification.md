## 最终一次 Windows 人工验收

1. 用 NSIS 安装包安装并启动；确认版本为 v1.2.0、主课表和 PDF/OCR 正常。
2. 在设置中导出备份，修改或删除一项测试课程后导入该备份；确认摘要、二次确认、课程/作息/提醒/5或7天偏好立即恢复，无需重启。
3. 点击“回到现在”；确认回到当前教学周并定位当前时间附近。
4. 在“关于”点击“检查更新”；无更新时出现明确提示，失败时仍可继续使用应用。
5. 打开 Widget、关闭主窗口到 Tray、从 Tray 恢复并最终选择“退出程序”；确认进程、Widget 和 Tray 均正常结束。
6. 确认课程提醒、作息保存和 Widget 保存没有回归。

真实 GitHub Draft Release 的 `latest.json`、下载签名校验与跨版本自动更新，必须在 RC 被接受、创建 v1.2.0 tag 后验证；当前阶段未创建 tag、未发布 Release。
