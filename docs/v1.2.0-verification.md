# v1.2.0 Release Candidate 验证记录

- 状态：Release Candidate 准备中，等待最终 Windows 安装态人工验收。
- 版本：1.2.0；SQLite schema 保持 4。

## 已完成

- 官方 Tauri 2 Updater 已启用：HTTPS GitHub Releases endpoint、`passive` Windows install mode、启动后非阻塞检查、关于页手动检查、更新说明、下载进度、失败重试和 Release 页面回退。
- 正式 updater 公钥已配置；生产私钥仅保存在仓库外。已验证本机 NSIS 与 MSI bundle 及对应 `.sig` 文件存在。
- Release workflow 使用 GitHub Actions secrets `TAURI_SIGNING_PRIVATE_KEY` 和 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`，并上传 updater JSON 与签名；不包含明文密钥。
- 课表支持“回到现在”、持久化 5/7 天偏好，以及 PDF 导入实际结果汇总。
- Settings / Schedule / Widget stability refactor (`e4d38bb`) 和 widget drag area (`d106720`) 保持冻结。
- Backup / Restore 已从产品、Rust commands、设置界面、filesystem capability、测试和文档中移除；SQLite schema 仍为 4。

## Course mutation stability

- 课程新增、编辑、删除、批量 PDF 导入、清空全部课程和作息/视图保存均通过 `spawn_blocking` 存储边界，避免同步数据库命令占用 Tauri runtime。
- 提醒刷新使用 generation 丢弃旧 mutation 的过期结果；空课程路径直接清空计划，不读取 handled history。
- Widget refresh 使用 single-flight/coalescing；刷新期间保留 last-known-good 课程内容，成功后原子发布新快照，失败显示错误状态而不白屏。
- 已保留 debug-only monotonic runtime trace，用于区分 mutation、DB、reminder、widget 和 event 阶段；不记录课程内容或密钥。

## PDF 文件选择器与设置保存并发回归

- 已完成的并发修复：`save_app_settings` 和 `patch_widget_settings` 只将既有 SQLite 操作调度到 Tauri blocking worker；数据库仍使用同一个受保护连接，事务与设置语义不变，且窗口 API 仍在释放数据库锁后执行。
- 当前新增的真实二分根因是 PDF 文件选择器取消路径：`open → cancel` 以前没有显式回到 idle，也没有统一释放前端操作 gate；这与 PDF 解析和课程数据库 mutation 无关，已按独立生命周期修复并加入取消/异常回归。
- PDF 路径已独立复核：主窗口按钮仅在实际读取 PDF 时禁用；`choosePdfFile` 直接调用 `plugin:dialog|open`，随后才读取文件并进入 PDF.js/OCR 解析。设置遮罩仅在设置对话框可见时作为有意的 modal backdrop 存在，不存在隐藏的全局 loading backdrop。
- 取消路径修复：文件选择器现在明确经历 `opening → selected/cancelled/error → idle` 生命周期；取消、`undefined`、空数组和异常均释放前端操作 gate，按钮不会保留在打开中状态，也不会让下一次设置保存继承旧状态。开发态 monotonic trace 记录 click、open-start/return、cleanup 和 operation-release，不记录文件内容。
- 新 UI 回归覆盖：正常 dialog invoke、widget 保存 pending、作息保存 pending、两项保存并发、保存失败后恢复可用、取消/异常/空数组/`undefined` 结果、取消后再次保存，以及关闭设置后可直接点击导入。9 个 DPI/窗口组合均 PASS。

## 最终一次 Windows 人工验收

1. 用 NSIS 安装包安装并启动；确认版本为 v1.2.0、主课表和 PDF/OCR 正常。
2. 点击“回到现在”；确认回到当前教学周并定位当前时间附近。
3. 在“关于”点击“检查更新”；无更新时出现明确提示，失败时仍可继续使用应用。
4. 打开 Widget、关闭主窗口到 Tray、从 Tray 恢复并最终选择“退出程序”；确认进程、Widget 和 Tray 均正常结束。
5. 确认课程提醒、作息保存和 Widget 保存没有回归。
6. 在 Widget 保存中、作息保存中，以及连续两类保存后分别关闭设置并点击“导入 PDF”；每次均确认 Windows PDF 文件选择器立即出现。保存失败后同样确认文件选择器可用。

真实 GitHub Draft Release 的 `latest.json`、下载签名校验与跨版本自动更新，必须在 RC 被接受、创建 v1.2.0 tag 后验证；当前阶段未创建 tag、未发布 Release。
