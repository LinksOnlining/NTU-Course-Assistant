# Phase 3.1 验证记录

日期：2026-09-09。状态：**PASS。**

## 实现边界

- “导入 PDF”仅允许选择 `.pdf`。取消选择不改变状态；读取期间显示状态，成功后只显示文件名、页数和文本块数量，明确说明课程表未修改。开发坐标预览只显示页码、x/y 和文本长度，不把可能含姓名或学号的原始块内容放入调试 DOM。
- `PdfExtraction` 保留文件名、页数、每页宽高，以及每个 `PdfTextItem` 的页码、原始清洗文本、x/y、宽高。文本做 NFC、无意义控制字符和用户确认无语义的 `■/▲/◆` 标记清理，保留中文、数字、括号、连字符和 `@`。
- PDF.js 按需加载；CMap 从锁定依赖在本地构建时复制到被 Git 忽略的静态目录，支持中文字体映射。没有 OCR、图像识别、课程识别、星期判断、Course 创建或 SQLite 写入。
- 非 PDF、损坏 PDF、加密 PDF 和无文本层均返回明确错误。无文本层提示“当前 PDF 可能是扫描版，首版暂不支持”。
