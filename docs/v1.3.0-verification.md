# v1.3.0 Academic Hub 验证记录

## 当前状态

当前为 Release Candidate，自动门禁与 v1.3.0 生产构建已通过；本轮 RC 阻断问题修复已完成，未创建 `v1.3.0` tag，未发布 GitHub Release，等待 Ethan 完成最终 Windows 10 安装态人工验收。

## 已实现范围

- `CourseOccurrence` / `CourseOverride`：停课、调课、换教室、补课。
- `AcademicTask` / `Exam`：Deadline、完成状态、考试信息。
- `getTodayDashboard` 与统一 Reminder 计划。
- Academic Hub 的今日、课表变化、任务、考试、学期管理页面。
- Widget NEXT / TODAY / DEADLINES 模式。
- schema 4→5 非破坏 migration，旧课程和设置保持可读取。
- 周课表和 Widget 读取 canonical occurrence，变化状态在课程卡片中可见。

## 本轮 RC 阻断修复

- 新增 `ChineseDateInput` / `ChineseDateTimeInput`：Task、Exam、课程变化编辑器使用可见的“年/月/日”字段和日历按钮，向领域层仍输出标准 ISO 日期/日期时间；不再依赖 Windows WebView 的 `yyyy/mm/dd` 原生占位文本。
- 修复 Academic Hub 页面滚动：应用级 `body` 保持固定窗口布局，Hub 自身承担纵向滚动并隐藏横向溢出，课表变化列表可从首条滚动到末条。
- 修复停课显示：`CANCELLED` canonical occurrence 在正式周课表布局中被过滤，因此停课不会继续显示为正常课程；Today、Widget 和提醒继续消费同一 canonical occurrence 并排除取消后的下一节课。
- 修复补课与覆盖解析：`MAKEUP` 不再替换原始课程，撤销 active override 可恢复基础 occurrence，同一 occurrence 的最新 active override 优先。
- 修复课程变化编辑器：调课、换教室、补课改为每条课程独立的可用编辑表单，保存前执行目标日期/时间冲突确认；停课仍只影响选中的一次课程。
