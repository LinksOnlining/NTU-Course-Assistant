## 本轮 RC 阻断修复

- 新增 `ChineseDateInput` / `ChineseDateTimeInput`：Task、Exam、课程变化编辑器使用可见的“年/月/日”字段和日历按钮，向领域层仍输出标准 ISO 日期/日期时间；不再依赖 Windows WebView 的 `yyyy/mm/dd` 原生占位文本。
- 修复 Academic Hub 页面滚动：应用级 `body` 保持固定窗口布局，Hub 自身承担纵向滚动并隐藏横向溢出，课表变化列表可从首条滚动到末条。
- 修复停课显示：`CANCELLED` canonical occurrence 在正式周课表布局中被过滤，因此停课不会继续显示为正常课程；Today、Widget 和提醒继续消费同一 canonical occurrence 并排除取消后的下一节课。
- 修复补课与覆盖解析：`MAKEUP` 不再替换原始课程，撤销 active override 可恢复基础 occurrence，同一 occurrence 的最新 active override 优先。
- 修复课程变化编辑器：调课、换教室、补课改为每条课程独立的可用编辑表单，保存前执行目标日期/时间冲突确认；停课仍只影响选中的一次课程。
- 修复学习中心分区标签在 CSS Grid 中被纵向拉伸的问题：标签保持紧凑高度，窄窗口改为横向滚动，不压缩文字。
- 重构课表变化交互为“课程 → 发生次数 → 操作”：课程列表按稳定 `courseId` 去重，支持课程名/教师/教室搜索与“全部/有变化”筛选；详情保留全部发生次数、中文日期、变化状态、现有覆盖和撤销入口，补课从课程详情顶部进入。
- 课程变化操作继续通过 canonical occurrence/resolver 与既有 `onDataChanged` 刷新链路驱动课表、Today、Widget 和 Reminder，不在 UI 重算规则。
- 修复 A：Academic Hub 内容现在位于独立的 `.hub-content-viewport`，标签与内容不再共享会拉伸/错位的直接 Grid 兄弟布局；内容从顶部开始排列，未使用负 margin、absolute、translate 或 fixed hack。
- 修复 B：发生次数操作改为每个 `.hub-occurrence-item-wrap` 内紧邻 occurrence 的 `.hub-occurrence-actions` 子区域，不再渲染列表底部的 `.hub-occurrence-panel`。
- 修复 C：停课、调课、换教室、补课和撤销使用 occurrence-local busy key，并在统一 `finally` 中清理；不再复用会让整页按钮进入等待光标的全局 `busy`。
- 修复 D：取消成功消息此前写入 Hub 级 `message`，被渲染到标签上方并在切换“今日”后泄漏为孤立“已停课”；现改为 occurrence-local `occurrenceMessage`，只存在于当前操作区域，切换分区会清理。
- 运行时追踪：每次 occurrence 操作记录 `confirmed → save-start → save-success → canonical-refresh-start → canonical-refresh-end → ui-update → operation-complete`，失败也经 `finally` 结束 operation gate。
- 旧安装态二进制曾早于本轮构建；本轮已用最新 NSIS 静默重新安装，安装态 EXE 时间与当前生产构建一致，避免用 stale bundle 验证旧 UI。

## 本轮页面状态边界重构

- 课程变化页由 `useCourseChangePageState` 管理课程选择、展开 occurrence、搜索/筛选、编辑器、操作消息和 typed `CourseChangeOperation`；AcademicHub 只保留学期、任务、考试等同级页面数据。
- 课表变化操作以 `operationRef` 防止同一事件循环内重复提交，并以 generation + tab cleanup 防止切换分区或卸载后旧 Promise 把消息、busy 或编辑器状态写回当前页面。
- 任务/考试/学期的页面 busy 不再作为“课表变化”按钮的 disabled 条件；课表变化只锁定当前 occurrence 的冲突操作。canonical 写入后的 `onDataChanged` 通知不会被派生刷新阻塞。
- “已停课/本周课程已停课”只由课程详情内的 `hub-week-status` 渲染；成功/失败消息只在当前 `hub-occurrence-actions` 内显示，离开课表变化分区会清理。
- 本项目 v1.2.0 已移除 Backup / Restore 及其运行时路由；因此没有可执行的“备份管理”页面，跨分区回归使用 Today/Tasks/Exams/学期管理切换验证相同的 cleanup/disabled 边界，不将不存在的功能宣称为已测试。
- 旧的 bottom `hub-occurrence-panel` 渲染路径不存在；每个 occurrence 最多拥有一个相邻的 inline actions 区域。

- 课程变化回归断言了 occurrence 操作区域是当前 occurrence 的内联子节点，`.hub-occurrence-panel` 数量为 0；重复点击同一 occurrence 可关闭/重新打开唯一操作区。
