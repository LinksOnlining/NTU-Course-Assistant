- `CourseOccurrence` / `CourseOverride`：停课、调课、换教室、补课。
- `AcademicTask` / `Exam`：Deadline、完成状态、考试信息。
- `getTodayDashboard` 与统一 Reminder 计划。
- Academic Hub 的今日、课表变化、任务、考试、学期管理页面。
- Widget NEXT / TODAY / DEADLINES 模式。
- schema 4→5 非破坏 migration，旧课程和设置保持可读取。
- 周课表和 Widget 读取 canonical occurrence，变化状态在课程卡片中可见。

## Windows 10 验收

Codex 未代替用户执行 Windows GUI 操作。Ethan 需要使用上述最新 NSIS 安装包完成一次安装态验收，至少覆盖：

- 默认打开“今日”学习中心，并能返回周课表；
- 停课、调课、换教室、补课及撤销/冲突提示；
- 学习事项新增、编辑、完成、恢复、删除和截止日期倒计时；
- 考试新增、编辑、删除、课程关联和倒计时；
- Widget 的 TODAY / NEXT / DEADLINES、显示/隐藏、锁定和重启恢复；
- 变化/任务/考试更新后提醒计划重建；
- 学期归档、历史查看、恢复，以及 v1.2.1 数据启动兼容；
- Tray、single-instance、退出和重启后的设置/课程数据恢复。

在上述人工验收完成前，本阶段保持 RC，不创建 tag 或发布 Release。
