# v1.1.0 RC2 verification

Status: **implementation, automated checks, Tauri desktop acceptance and v1.1.0 release build passed**.

## Changes

- Widget writes are field-level Rust patches with database readback, so delayed geometry writes cannot replace newer mode, lock, or enabled preferences.
- App and period settings now use canonical post-transaction readback before React accepts a save.
- The period editor can apply one 20–120 minute duration to its current draft while retaining the first start and every existing break.
- PDF extraction retains the PDF.js text fast path. PDFs without text use bundled local Tesseract OCR (`chi_sim` and `eng`) and return the same positioned text model to the existing parser.
- Non-fixed practice detection requires both a practice token and a `(共 N 周)` structural marker, so fixed-course metadata containing `训练` cannot become a false candidate.

## Local PDF evidence

The user-supplied PDF was read only and was not copied into this repository. Under the app PDF.js configuration it used the text path, with 3 pages and 260 text items. Before the parser fix it produced one false practice candidate from a fixed-course metadata fragment containing `训练`; after the fix both the live source flow and the production frontend bundle produced 20 candidates: 17 fixed arrangements and 3 non-fixed practices. It is therefore a regression case for the former false scan classification and the later unsupported-structure report, not an OCR fallback sample.

An anonymous local bitmap rendering was recognized by the bundled local OCR engine. Its text was not committed.
