# Phase 4.1：南通大学教务系统入口与数据源调查（已由用户取消）

日期：2026-09-10
结论：**CANCELLED BY USER**。本文仅归档既有公开资料调查，不再作为后续开发条件。

## 已确认的公开事实

- 南通大学本科生教务系统在官方资料中称为“南通大学-教学综合信息服务平台”，直接入口为 [`https://tdjw.ntu.edu.cn`](https://tdjw.ntu.edu.cn)。[教务处 2026 年选课通知](https://jwc.ntu.edu.cn/2026/0825/c2701a297462/page.htm) 与 [2026 年微专业通知](https://jwc.ntu.edu.cn/2026/0904/c2701a298148/page.htm) 均在当前学期使用该入口。
- 官方教务处网站的“教务管理系统”应用入口会进入学校[统一身份认证平台](https://authserver.ntu.edu.cn/authserver/login?service=https%3A%2F%2Fe.ntu.edu.cn%2Flogin)。这证实了认证依赖，但不等同于可由本应用保存或复用认证状态。
- 官方操作资料与通知确认，系统中存在“信息查询 → 班级课表打印”路径。[2026 年重修通知](https://jwc.ntu.edu.cn/2026/0316/c2701a287305/page.htm) 直接描述该菜单；历史官方操作材料还显示“学生课表查询”菜单项。
- 公开资料未证实**个人**课表具有 Excel、CSV、ICS、JSON 或 PDF 下载功能；“班级课表打印”也不能据此推断个人课表的实际导出格式。

## 未确认且不会猜测的事项

- 个人课表页面的准确菜单路径、学期选择方式，以及是否存在正式导出或打印按钮。
- 课程数据是否来自服务端 HTML、iframe、XHR/fetch、JSON、form POST 或其他机制。
- 登录后请求的 URL 模式、method、参数字段、响应 Content-Type、CSRF/session 依赖及课程字段语义。
- 是否存在可稳定复用的结构化个人课表数据源，以及实际周数、单双周、节次和时间的表达形式。

本调查没有登录、没有尝试认证、没有请求任何个人数据，也没有保存密码、Cookie、Token、Authorization、验证码、学号或完整 HAR。

## 技术方案比较

| 排名 | 方案 | 结论 | 原因与限制 |
| --- | --- | --- | --- |
| 1（条件成立时） | 官方个人课表导出或打印为 PDF | 最优 | 用户主动操作、认证边界最小；若为 PDF，可直接复用已完成的 Phase 3，不需要 Phase 4 新导入器。尚未证实该能力存在。 |
| 2 | 用户主动提供已登录个人课表的脱敏 HTML/结构化导出 | 候选 | 不保存认证资料，可在 Phase 4.2 解析为现有 `ImportCandidate[]`；需要先确认页面实际结构和稳定性。 |
| 3 | 用户在浏览器 Network 中主动检查本人课表请求并提供脱敏 JSON/字段结构 | 候选 | 若响应稳定 JSON，解析成本低；应用不接收 Cookie、Token、Authorization 或完整 HAR，仍需确认该响应与本人会话的认证边界。 |
| 4 | 应用内 WebView 打开官方登录页 | 暂不采用 | 可能受统一认证、验证码和会话持久化影响；本阶段不实现 WebView 登录、回调或凭证存储。 |
| 5 | 读取 Chrome/Edge Cookie 数据库 | 拒绝 | 高隐私、高权限且脆弱；不符合用户主动授权数据源原则。 |

## 推荐的下一步与 Phase 4.2 输入

优先检查官方个人课表页面是否提供“导出”“下载”“打印”或“保存 PDF”。若其输出可被用户主动保存为 PDF，继续使用 Phase 3 的既有 PDF 流程。

若没有合适的官方导出，Phase 4.2 的候选输入应是**用户主动提供的、已脱敏的本人课表页面字段结构或 JSON 响应结构**。该适配器只能输出既有 `ImportCandidate[]`，随后完全复用 PDF 的预览、修正、`CourseProposal`、重复/冲突判断、最终确认和 SQLite transaction；不得直接创建 `Course`。

应用不需要、也不得保存用户账号密码。认证始终由用户在官方页面完成；应用只接收用户明确导出的无认证数据。

## 需要用户提供的最小非敏感信息

请在浏览器中自行登录 `https://tdjw.ntu.edu.cn`，打开**自己的个人课表**后，只提供以下任一项：

1. 是否有“导出 / 下载 / 打印 / PDF / Excel / CSV / ICS”入口，以及其非敏感截图或文件类型。
2. 课表页面的菜单路径，以及页面上可见字段名称，例如课程名、教师、地点、星期、节次、周数、学期。
3. 若数据由 Network 请求加载：只提供请求 method、脱敏 URL 路径模式、非敏感参数**名称**、响应 Content-Type 和已删除个人信息后的 JSON/HTML 字段结构。

不要提供密码、Cookie、session、token、Authorization、验证码、学号、姓名，或完整 HAR。HAR 若需要参考，必须先删除所有敏感 header、Cookie、认证字段和个人身份字段，只保留字段名与结构。
